# Code of Conduct

Be respectful. Harassment, personal attacks, and other clearly inappropriate
behavior aren't welcome in this project's issues, pull requests, or discussions.

This is a solo-maintained project with no dedicated moderation. There is no
promise of investigation or response — but the maintainer may remove content or
block accounts at their discretion. For serious abuse, use
[GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
